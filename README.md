# TagLens Android

Android 7.0+，ARM64。APK 内置原生 AprilTag 3.4.3 引擎。使用本机相机及系统文件选择器，应用本身不申请联网权限。

- 实时模式使用后置相机独立预览，取 NV21 亮度平面输入检测。识别繁忙时跳过新到的旧队列帧，最多使用 4 个检测线程。
- 拍照精扫及导入照片使用最多 6 个检测线程，ARM NEON 灰度转换，原图重叠分块和全图概览。按同一 ID 的图像位置合并重叠检测。不同位置的同一 ID 分开计数。
- 包含八种家族和 144 码示例。JSON 含 ID、角点、中心、图像内方向与耗时。照片坐标为按 EXIF 转正后的原图像素。实时坐标为按屏幕方向转正后的分析帧像素。

## Linux 命令行构建

需要 JDK 17、Android Platform 35、Build Tools 35.0.0、Android NDK r27d、zip。设置下列环境变量后运行 `./build.sh`。

- `JAVA_HOME` 指向 JDK 根目录
- `ANDROID_PLATFORM_JAR` 指向平台的 android.jar
- `ANDROID_BUILD_TOOLS` 指向含 aapt2、d8、zipalign、apksigner 的目录
- `ANDROID_NDK_HOME` 指向 NDK 根目录
- `APRILTAG_SRC` 指向 AprilTag 源码，默认使用 `vendor/apriltag`
- `TAGLENS_KEYSTORE`、`TAGLENS_STOREPASS` 和可选的 `TAGLENS_KEY_ALIAS` 指向你自己的签名密钥。密钥不在源码包中。

输出 `build/TagLens-Android-arm64.apk`。预置签名的 APK 可以侧载到 Android。覆盖安装需要保持同一包名和签名。

AprilTag 许可证见 `assets/APRILTAG-LICENSE.txt` 和 `vendor/apriltag/LICENSE.md`。测试标签来自 AprilRobotics/apriltag-imgs。

## 1.1

- 结果直接在取景区展开，角点可以逐项展开查看。设置和家族选择使用统一圆角和淡入淡出。
- 设置支持深蓝绿、白底黑字、黑底白字三种外观，以及实时分辨率、实时和精扫线程、标注显示和标定板补扫。
- 6 × 6 补扫适用于从左下角 ID 0 起，向右、向上递增的 tag36h11 板。至少四个分布充分的已识别码用来拟合透视网格。缺失格会重新采样实际像素并校验码字，只有通过校验的码才计数。补扫输出的角点由拟合网格和每格微调估算。
- 用户截图离线回归识别到 ID 0–35。遮住 ID 0 时返回 35 个。独立 144 码样板仍返回 144 个。

## 1.2

- 结束扫描或从实时扫描进入结果时，定格最近一张已完成识别的画面。画面、角点、识别框和导出坐标来自同一次检测。预览缓冲区在实时扫描中复用，只在结束时生成定格图片。
- 设置中的「识别框颜色」可选预设、跟随主题或输入 6 位 RGB 色值。边框、方向线和 ID 一起换色，设置会保存。

## 1.3

- 设置中的「密集标定板增强」在 tag36h11 下默认开启。新增分割遍会切断候选方框和棋盘角点之间的细小连接，解码仍使用原始图像像素。两遍结果仅合并同位置的重复检出，同 ID 出现在不同位置时分别计数。增强没有固定行列数。
- 设置内附两个 16 × 16 示例。标定板含 ID 0–255，普通阵列的 256 个标签均为 ID 27。
- 原生引擎回归覆盖 6 × 9 实拍照片 54/54、旧图 36/36、遮挡图 35/35、带透视和模糊的合成 16 × 16 标定板 256/256、合成同 ID 阵列 256/256 和旧 144 码示例。实时和精扫的降采样参数均已在测试环境验证，手机实时帧率有待实测。

## 1.4

- 设置可选 AprilTag 识别、棋盘格标定、AprilTag 标定板标定。棋盘格输入的是方格数，8 × 11 方格对应 7 × 10 个内角点。OpenCV 4.12.0 提取棋盘格亚像素角点及求解相机参数。
- AprilTag 标定板输入行列、起始 ID、标签黑边外缘的边长、相邻黑边间距及首行方向。适用每行由左到右连续编号、标签方向一致的板。标定使用实际检测角点，避免用网格拟合补出的坐标参与求解。
- 每组使用同一相机、分辨率和板型。至少采集 8 张不同姿态，建议 15–25 张，覆盖图像中心和四角。可采集当前取景帧或逐张导入照片。JSON 导出 K、D、像素尺寸、总体及逐图重投影误差。较大的导入照片按实际参与计算的缩小后像素尺寸标定。
- 系统通过 Android Camera2 暴露的外接 USB 摄像头可在设置选择。系统未枚举的 UVC 设备不能由此版本打开。USB 精扫使用取景流帧，内置后置仍使用拍摄原图。
- 精扫增大概览尺寸并在概览与原图重叠分块上运行两种检测采样尺度，按位置合并结果。照片焦点、曝光或板子运动变化仍会影响识别。
- 构建脚本从 Maven Central 下载 OpenCV Android AAR，许可证见 assets/OPENCV-LICENSE.txt。

## 1.5

切换工作模式后，主页立即展示相应标题、板型参数和操作按钮。棋盘格标定隐藏标签家族选择，AprilTag 标定保留家族与板型选择。点「开始标定」后，预览以约 350 毫秒最短间隔在后台检测有效角点，绘制棋盘内角点，显示是否可采集。点「采集样本」保存最近一次已验证取景帧的角点，无需再拍一张 JPEG。达到 8 张后主页的「计算标定」直接启动求解。

离线回归从用户提供的相机预览截图中裁出取景区域，在实时检测尺度和旋转 90° 后均找到 70/70 个棋盘格内角点。实时界面与相机未在目标手机上复测。

## 1.6

- AprilTag / ArUco 识别的字典选择新增 OpenCV 4X4、5X5、6X6、7X7 各 50/100/250/1000、ArUco ORIGINAL 和 ArUco MIP 36h12。实时和导入照片使用相同选择，返回同一套 ID、边框、方向和 JSON 格式。
- AprilTag 标定入口增加「规则标记阵列」和「ChArUco 混合棋盘」。混合棋盘使用 ChArUco 内角点，可填实际方格边长、标记边长、起始 ID 和旧版排列。字典支持全部新增 ArUco 字典及 OpenCV 支持的 AprilTag 36h11、25h9、16h5。
- 模式、板型和识别字典选择后提供带过渡的示例图；主页「示例图」可再次打开。
- 原图离线回归：60332 的 ArUco ORIGINAL 检出 100/100；60331 的 10×10 ChArUco（6X6_50，旧版排列）检出 73 个内角点，旋转 90° 后仍检出 73 个。内置 ChArUco 示例检出全部 81 个内角点。目标手机的相机、UI 和标定会话还需实机复测。

## 1.7

- 标定和识别结果可复制完整 JSON，也可用微信、QQ 或其他应用分享。附件通过只读链接从应用缓存发送，也可选择分享纯文本。
- 主页「示例图」和「设置」保留独立间距。「设置 → 外观」下的「液态玻璃」开关可搭配三种配色，切换后即时生效。
- 安装包显示为「TagLens 1.7」，包名为 `com.taglens.scanner.share`，可与早期版本并存。首次安装需重新授予相机权限并设置偏好。
- 若仅重建 Java 界面，可设置 `TAGLENS_PREBUILT_APK` 为兼容的 TagLens 1.6 ARM64 APK 的绝对路径，构建时沿用其中的原生库。常规全量构建仍使用 Android NDK。

## 1.8

- 液态玻璃模式在 Android 13 及以上使用 AGSL 着色器。取景状态、结果浮层与弹层使用相机或定格图片作为背景，边缘执行折射采样，正文区域加深磨砂，按压时在触点附近渐亮。Android 7–12 使用兼容外观。
- 相机背景使用低分辨率 PixelCopy，最高约 15 次/秒。关闭液态玻璃后不采集该背景。
- 包名和签名沿用 1.7，可直接更新 1.7 并保留设置。1.6 的安装签名不同。

## 1.6.1 回退修订版

恢复经典的纯色界面并移除液态玻璃。「示例图」和「设置」各有独立的 48 dp 高点击区域，间距 12 dp。保留复制结果和分享功能。

显示版本为 1.6.1，内部版本号高于 1.8。沿用 1.7 / 1.8 的包名和签名，可覆盖这两个版本。

## 1.6.2

规则标记阵列标定在 tag36h11 的常规检测无法建立样本时，增加一轮 OpenCV 检测。采集前核对读到的 ID 和空间排列，并依据网格方向匹配实测的标签角点，可兼容标签自身旋转的板。参数栏显示起始 ID。

用用户截图的取景区域离线复测，原检测返回 0 个标签，新检测返回 32 个。旋转 90°、180°、270° 后分别返回 28、30、30 个。该板为 8 × 8，从底行左侧 ID 1 开始。保留实际打印尺寸和间距设置。

## 1.6.3

起始 ID 可疑时，在当前编号附近重新比较阵列几何一致性。确认相邻起始 ID 更符合实际排布时提示修改，避免把跨行错配的角点采为样本。停止取景时保留当前未通过校验的原因；若没有失败信息，则显示实际已采集张数。
